# React Native Market Uygulaması 

## 📱 Proje Özeti

Bu uygulama, bir online market alışveriş arayüzünü statik veriler ve görseller kullanarak simüle eder. Aşağıdaki bileşenleri içerir:
- **Header (Üst Menü):** Menü, arama, sepet ve bildirim ikonları
- **Arama Çubuğu (Search Bar)**
- **Kategori Menüsü (Category Menu):** İkonlu kategoriler
- **İndirimli Ürünler (Offers)**
- **Önerilen Ürünler (Recommended)**
